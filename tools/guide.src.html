What it is

Box Ctrl makes labels for tool boxes. Pick your box, add your logo, list what's in each box, and print. It doesn't print anything by itself: it gives you sheets for the Liene app or your browser's print dialog.

New here? Take the tutorial. It builds a sample set of labels with you and won't touch your list.

What you need

Box Ctrl doesn't print on its own. It makes files and pages for one of two routes.

Sticker labels

  • A Liene PixCut S1 photo sticker printer and cutter.
  • The Liene Photo app for Mac.
  • Liene 4 × 7 sticker paper.

The sheets are made for this printer, app and paper, and it's the only sticker printer tested. Other sticker printers haven't been tested, and a sheet made here may not print or cut correctly on them.

Paper cards

  • An office printer that takes Letter or A4 card stock.
  • Card stock, 135 gsm or heavier for Systainer cards.
  • A trimmer or a sharp knife and rule.

These pages go through your browser's print dialog, so there's no separate PDF export. To keep a PDF, choose Save as PDF there, and print it at 100 %.

The three steps

  1. Template Design: set what every label shares. Pick the box size, upload your logo, and add an owner line and ID prefix.
  2. Label Information: list your boxes, by hand, with Add standard tools, or from a spreadsheet.
  3. Label Print: choose a route and print.

Measuring your box

Measure the space the label sits in, in millimetres, and take off a little so it clears any tabs or edges. Enter it under Custom size. Print one label and check it before a full run.

Other boxes

Two Systainer sizes are built in: the standard card and the Systainer³ S card. The standard card is 80 × 52 mm, for a sticker or a paper card, a size tested on a real cover.

Untested sizes. Box size also has starting sizes for the DEWALT TSTAK plate at 97 × 19 mm, and for Milwaukee PACKOUT handles at 101.5 × 18, 117 × 18 and 150 × 18 mm. They come from community design files, not from DEWALT or Milwaukee, and we haven't checked them on a real box. PACKOUT length changes with the box, and handles can vary by 2 to 3 mm. A PACKOUT handle is shaped and textured, so a sticker may not hold on it, and you may need a printed strip behind it.

Print one on plain paper and hold it against your box first. To adjust it, choose Custom size, which starts from the size you had.

We haven't found a label size for ToughSystem, L-BOXX, MakPac or metaBOX, so measure yours and use Custom size. Long, thin labels get the Strip shape, which leaves off the contents.

Printing on the Liene

  1. Press Save sheets and open a sheet in the Liene Mac app.
  2. Keep the lock on. Type W 90.0, H 170.0, X 0.0, Y 0.0.
  3. Set cutting mode to Separate, and Border to match Cut border in Label Print.
  4. Leave AI remove background off, then print on Liene 4 × 7 sticker paper.

Only tested on the Liene PixCut S1, with the Liene Photo Mac app.

Printing on an office printer

  1. Choose Office printer in Label Print, and pick Letter or A4.
  2. Press Print. Your browser's print dialog opens.
  3. Set Scale to 100 %, and use card stock. For Systainer cards, 135 gsm or heavier.
  4. Check that the line on the page measures 50 mm.
  5. Trim on the crop marks.

Owner line

The owner line prints bottom left of every label, up to three lines. Press Return for a new line. A phone number or address helps a box find its way home if it gets left behind, but it shows to anyone who sees the box, and it stays in any backup you export. Long, thin labels leave the owner line off.

Logos and names

Only add a logo you own or have permission to use. Box Ctrl asks you to confirm that each time you add one. You're responsible for how you use it, and for the names you print. Box Ctrl doesn't check logos. It keeps the logo in this browser, and in your own GitHub repo if you connect one, and takes no responsibility for your use of it.

Standard tools list product names so you can find your tool. Those names belong to their makers. Check each one against your tool.

Standard tools from manufacturers

Tools from Festool, Milwaukee, DEWALT, Bosch and Makita are already loaded, so you don't have to type them. Press Add standard tools, pick a maker, and pick your tools. Each one adds a box in that maker's group, ready to edit. The magnifier on a row fills in that one box.

Keeping your list

There are no accounts. Your list saves in this browser, on this computer, and clearing browser data removes it. Keep a copy with Export backup, or connect your own private GitHub repo, which keeps one for you.

Export spreadsheet saves a .csv you can open in Excel, Numbers or Google Sheets. Add your own columns, such as Location or Purchase date. Box Ctrl keeps them with each box, never prints them, and puts them back when you export. To bring it back, press Open file.

Export backup saves everything, including your logo and group colours, as a .json file.

Printing a second set

Already printed some? Set Start numbering at to the next number in Template Design, then add your new boxes. If they're on the same list, set Quantity to 0 on the boxes you've already printed.

Errors and fixes

The name is small: shorten it.

Left off at this size: the label is too small for everything. Shorten the text, or pick a bigger size.

That file has no Name column: start from the template.

An older or protected Excel file: save it as .xlsx or .csv.

This browser isn't keeping your list: use Export backup before you close.

Your list on GitHub

New to GitHub? Follow Set up GitHub, step by step.

You can keep your list in your own private GitHub repo, so every browser you connect has it, with a history of every change. It's optional. Box Ctrl works fully without it, and this browser stays the working copy.

  1. On GitHub, make a new private repo, such as ctrl-data. Keep it private: it holds your logo and owner line.
  2. Make a fine-grained personal access token for that one repo, with Contents set to read and write and nothing else. Tool Ctrl uses the same repo and token, so make it once.
  3. In Label Information, press Connect to GitHub and enter the repo as owner/name and the token. If Tool Ctrl is already connected in this browser, press Use Tool Ctrl's repo instead.

Box Ctrl writes box-ctrl.json, and box-ctrl-logo.png when you've added a logo, beside Tool Ctrl's tool-ctrl.json. Every change saves here at once and goes to GitHub a few seconds later, as one commit. Offline, changes wait here and go when you're back. If two devices change the same thing, Box Ctrl shows both and asks which to keep.

The token stays in this browser only, never in a file or link. Every WOODWERD tool runs from woodwerd.github.io, so Tool Ctrl and Box Ctrl can share it in the same browser. That's why it should reach only that one private repo. Disconnect deletes it here.

A logo goes to the repo as its own file. Removing it deletes the file, but older commits still hold it. Deleting the repo is the only way to remove it for good. Another device asks you to confirm the logo once before using it.

Get boxes from Tool Ctrl reads Tool Ctrl's record from the same repo and shows what's new and changed before anything changes. Only IDs, names, kinds, contents, groups and icons come across, never warranty details, locations or notes. Boxes Tool Ctrl doesn't have stay on your list. Without GitHub, use Tool Ctrl's Export for Box Ctrl and Open file here.

Privacy

Box Ctrl has no analytics. Unless you connect your own GitHub repo, it makes no network requests, and your list, spreadsheets and logo stay on this device. Once connected, it talks only to api.github.com, only for that repo, and sends your list and logo there. Spreadsheets you open are never sent. Keep the repo private.
